<span className="label">integrationen</span>

Wenn deine Firma Microsoft 365 nutzt (Outlook, Exchange), kann dein Agent direkt mit deinem Firmen-Postfach arbeiten: neue E-Mails lesen und dich sofort informieren, Antworten vorbereiten, in deinem Namen senden (nur mit deiner Freigabe) und deinen Kalender nutzen.

Das Beste daran: **Du musst fast nichts tun.** Dein Agent führt die Einrichtung selbst durch — du beantwortest ihm ein paar Fragen, deine IT erledigt einen einmaligen Schritt, fertig.

## Was dein Agent danach kann

| Können | Wie |
| ------ | --- |
| E-Mails lesen | Nur in den Postfächern, die du festlegst |
| Auf neue E-Mails reagieren | Dein Agent wird bei jeder neuen E-Mail sofort geweckt — ohne dass du etwas tun musst |
| E-Mails beantworten und senden | An dich direkt; an alle anderen nur als Entwurf oder nach deiner Freigabe |
| Kalender | Termine lesen und verwalten |

<Note>
**Kein Passwort, kein Login.** Dein Agent bekommt niemals dein Microsoft-Passwort. Der Zugang läuft über ein technisches Zertifikat, das deine IT einmalig hinterlegt — und gilt ausschließlich für die Postfächer, die deine IT ausdrücklich freigibt.
</Note>

## So läuft die Einrichtung

<Steps>
  <Step title="Sag deinem Agenten, was du willst">
    Schreib deinem Agenten einfach, z. B.: *„Bitte binde mein Microsoft 365 an."*

    Er fragt dich dann ein paar Dinge:
    - **Welche Postfächer** soll er lesen? (z. B. dein eigenes, `office@…`)
    - **In wessen Namen** darf er E-Mails senden?
    - **An wen** darf er direkt senden? (alles andere wird nur Entwurf)
    - **Wer ist deine IT-Ansprechperson?** (Name + E-Mail-Adresse)
  </Step>
  <Step title="Dein Agent kontaktiert deine IT">
    Dein Agent schickt deiner IT eine E-Mail mit allem, was sie braucht: eine
    Schritt-für-Schritt-Anleitung und das nötige Zertifikat. Deine IT richtet
    damit den Zugriff in eurem Microsoft 365 ein — einmalig, etwa 15–30 Minuten
    Aufwand, und nur für genau die Postfächer, die du genannt hast.

    Du musst hier nichts tun. Falls die IT nicht antwortet, erinnert dich dein
    Agent nach ein paar Tagen.
  </Step>
  <Step title="Dein Agent schließt ab und meldet Vollzug">
    Sobald deine IT zwei Kennungen zurückschickt, richtet dein Agent alles
    fertig ein, prüft die Verbindung und meldet sich bei dir, wenn alles
    funktioniert. Ab dann wecken ihn neue E-Mails automatisch.
  </Step>
</Steps>

<Tip>
Nach dem IT-Schritt kann es **bis zu zwei Stunden** dauern, bis Microsoft die Freigaben überall verteilt hat. Dein Agent weiß das und probiert es geduldig erneut — du musst nichts tun.
</Tip>

## Sicherheit: Was eingebaut ist

- **Nur freigegebene Postfächer.** Dein Agent kann ausschließlich auf die Postfächer zugreifen, die deine IT freigegeben hat — alles andere wird technisch blockiert, doppelt: bei Microsoft und im Agenten selbst.
- **Senden mit Leitplanken.** E-Mails an Personen außerhalb deiner Freigabe-Liste werden nie direkt verschickt, sondern landen als Entwurf zur Durchsicht.
- **Kein Geheimnis unterwegs.** Der private Schlüssel des Zertifikats bleibt immer beim Agenten. Deine IT erhält nur den öffentlichen Teil — der ist unkritisch.

## Häufige Fragen

<AccordionGroup>
  <Accordion title="Was muss meine IT können?">
    Eure IT braucht Administrator-Zugriff auf euer Microsoft 365 (Entra/Azure).
    Die Anleitung, die dein Agent mitschickt, führt durch jeden Schritt —
    inklusive fertiger Befehle zum Kopieren. Bei Bedarf kann sich deine IT die
    Anleitung vorab ansehen:
    [Technische Einrichtungsanleitung (Deutsch)](https://github.com/MakersLab-ai/m365cli/blob/main/docs/azure-setup.de.md).
  </Accordion>
  <Accordion title="Kann der Agent später weitere Postfächer dazubekommen?">
    Ja. Sag es einfach deinem Agenten — wenn das Postfach von deiner IT schon
    freigegeben ist, geht das sofort; sonst stößt er den kurzen IT-Schritt
    dafür an.
  </Accordion>
  <Accordion title="Funktioniert das auch mit privaten Outlook.com-Konten?">
    Nein. Die Anbindung ist für Microsoft-365-Firmenkonten gedacht. Für private
    Postfächer sprich uns einfach an — dafür gibt es andere Wege.
  </Accordion>
  <Accordion title="Sieht der Agent auch alte E-Mails?">
    Beim Start merkt sich dein Agent nur den aktuellen Stand — er arbeitet
    nicht ungefragt dein Archiv durch. Er reagiert auf neue E-Mails; ältere
    liest er nur, wenn du ihn danach fragst.
  </Accordion>
  <Accordion title="Was passiert, wenn ich die Anbindung beenden will?">
    Deine IT kann den Zugriff jederzeit zentral entziehen — damit ist sofort
    Schluss, ohne dass am Agenten etwas geändert werden muss.
  </Accordion>
</AccordionGroup>
